# Ibrahim Issa — Professional Portfolio

This is a static HTML/CSS/JavaScript portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Open your repository: `https://github.com/issa6064/ibrahim-issa-portfolio`
2. Upload **everything inside this folder** (including `index.html`, `style.css`, `script.js`, and `assets`).
3. Commit the changes.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then save.
7. Your portfolio should appear at:
   `https://issa6064.github.io/ibrahim-issa-portfolio/`

The documents are already included in `assets/documents/`.
